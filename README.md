## 👋 A little about me

I'm a developer who likes turning random ideas into **actual software**.

I mostly build with **TypeScript, React, Next.js, and Python**, but I also like experimenting with desktop apps, audio, automation, CLI tools, themes, and weird ideas that probably didn't need to become projects.

I learn by building:

> **Idea → prototype → break it → fix it → add too many features → somehow ship it**

I'm especially interested in the space between **good engineering and a good experience** — making things work well *and* making them enjoyable to use.

## 🚀 What I'm building

### 🎨 [VibeSorter](https://github.com/Ava-91/VibeSorter)

A local-first Python CLI for organizing image libraries by **visual vibe** rather than semantic meaning.

It analyzes things like brightness, saturation, contrast, color balance, and spatial features to classify images into overlapping aesthetics.

**Python · Pillow · SQLite · CLI · Image Analysis**

> *What if instead of asking “what is this picture?”, we asked “what does this picture feel like?”*

### 📸 [RepoShot](https://github.com/Ava-91/reposhot)

A tool for turning GitHub repositories into beautiful, customizable preview images.

**Next.js · React · TypeScript · Tailwind CSS**

→ [Live demo](https://reposhot.vercel.app/)

### 🔊 [Ovrino](https://github.com/Ava-91/ovrino)

**TypeScript · Audio · Application Development**

### 🎵 [music-sync](https://github.com/Ava-91/music-sync)

Built around the idea that your music collection should be something you can **manage, compare, and move between systems** without losing control of it.

**Python · Music Libraries · File Operations**
